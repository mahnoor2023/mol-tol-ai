# Contributing

This repository contains a public SDK candidate and static portfolio materials. The current project license is All rights reserved; no contribution or reuse rights are implied. Until the owner approves an explicit contributor and licensing policy, please use issues for discussion and do not submit code contributions.

For any future approved contribution:
- Keep API credentials and customer negotiation data out of source and examples.
- Use clearly labeled synthetic fixtures.
- Preserve server-side policy enforcement and tenant authorization in documented examples.
- Include focused tests and state what was verified versus simulated.

No pull request should be treated as accepted until the repository has an owner-approved license and contribution terms.
