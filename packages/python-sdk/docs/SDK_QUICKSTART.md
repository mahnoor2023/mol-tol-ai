# SDK quickstart (synthetic example)

Mol-Tol does not currently provide a hosted API endpoint. This guide applies when an API operator has provisioned buyer and seller tenant keys and supplied a compatible base URL.

## 1. Build and install the client

The client has no runtime dependencies. From the SDK directory:

```powershell
python tools/build_wheel.py --output .\dist
python -m pip install --no-index --no-deps .\dist\mol_tol_sdk-0.4.0-py3-none-any.whl
```

`pip install .` is also supported through the declared PEP 517 backend, but may need setuptools from an approved package source. The included wheel builder needs only Python's standard library.

## 2. Configure credentials in the server process

Use environment variables or a secret manager. Do not commit values, paste them into browser code, or echo them to a terminal transcript.

```powershell
$env:MOLTOL_API_URL = 'https://operator-approved-api.example'
$env:MOLTOL_BUYER_API_KEY = '<provided privately by API operator>'
$env:MOLTOL_SELLER_API_KEY = '<provided privately by API operator>'
$env:MOLTOL_SELLER_TENANT_ID = '<seller workspace id>'
```

The host and credential values above are documentation placeholders; no service is hosted at that example domain.

## 3. Run the synthetic workflow

```powershell
python examples/public_pilot.py
```

The example creates a fictional USD session, submits an offer, requests a server-generated counteroffer, records mutual acceptance, finalizes once with a unique idempotency key, and verifies the proof against API state. It reports API errors with HTTP status/code; the SDK connection error avoids printing the credential or URL.

## Boundaries

- Currency and quantity are immutable session terms. Prices use integer minor units; no currency conversion occurs.
- Buyer maximum and seller minimum policies are configured and enforced by the server. Public session views must not contain those private values.
- The counteroffer in the example is generated by the deterministic server policy. It is not model inference.
- Only an API operator can provision an API and scoped tenant keys. This SDK creates no identity, hosted API, or public demo credential.
- A SHA-256 fingerprint allows content recomputation; it is not authentication, a digital signature, or tamper-proof storage.
