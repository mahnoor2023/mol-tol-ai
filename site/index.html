A CLEAR TRUST BOUNDARY

From proposal to checkable agreement.

The service owns negotiation state and policy checks. An agent can suggest terms; the API decides whether those terms are allowed.

01 / PROPOSE

Exchange structured terms

Represent prices as integer minor units, keep session currency fixed, and bound the number of turns.

02 / ENFORCE

Apply server-side policy

Authorization, private buyer and seller limits, and state transitions stay under API control.

03 / VERIFY

Inspect agreement evidence

Recompute a SHA-256 fingerprint to check content consistency. A hash is not an identity signature.

DEVELOPER PROJECT

Built around an HTTP API and Python SDK.

The local prototype includes a FastAPI service, a dependency-light Python client, a Next.js console, tenant-scoped credentials, USD/PKR accounting, and automated regression tests.

The SDK source and API contract are included in this repository. This static page does not connect to a hosted API.
