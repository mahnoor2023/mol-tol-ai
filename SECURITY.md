# Security policy

Mol-Tol is a prototype and has not received an independent security audit. Do not send production credentials, customer data, or confidential negotiation terms to any demo or unverified endpoint.

Please do not post exploitable security details in public issues. Use GitHub Private Vulnerability Reporting if it is enabled for this repository; otherwise contact the repository maintainer privately through the maintainer profile. No response-time guarantee is offered for this prototype.

The current SDK repository does not host an API. Tenant keys must remain in trusted server-side processes. The SHA-256 agreement fingerprint checks content consistency; it is not authentication or tamper-proof storage.
