# Prototype limitations

- No hosted Mol-Tol API is provided by this repository.
- Real LLM inference is unverified (`inference_count: 0`); deterministic examples are not model responses.
- The included static page is a marketing/portfolio artifact and does not connect to an API.
- The private local prototype has not received an independent security audit and is not production security certified.
- Synthetic scenarios do not establish market performance, customer demand, revenue, or commercial validation.
- No live payments or native Android APK are included.
- Agreement SHA-256 fingerprints permit content recomputation; they are not signatures, authentication, trusted timestamps, or tamper-proof storage.
